# DFA minimization test cases (Myhill-Nerode table filling)
#
# Each test:   ### TEST <number> base <0|1> <description>
#              --- input       (input format of DFA_minimizer_final.cpp)
#              --- expected    (one line per transition: {from} {to} symbol)
#
# "base" is the first state number used on the board for that example:
# board examples 1 and 2 are drawn with states 0,1,2,... and examples 3 and 4
# with states 1,2,3,... Test 5 is not from the board.
# E = error state (no transition).  {1,2} = states 1 and 2 merged.
